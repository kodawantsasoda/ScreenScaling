# ScreenScaling
A template for screen scaling using Raylib and C++. We can use a virtual resolution to draw everything to and design our game around, and size up that texture up or down depending on the size of the window. Supports 1080p and 4k due to the intial dimensions of the virtual resolution being able to nicely multiply into those resolutions. Note that for aspect ratios that mismatch the original virtual resolution, white boxes will appear either vertically or horizontally to account for the ratio mismatch. If it's the same aspect ratio (like scaling up to fullscreen) the resolution will scale up evenly so no letterboxes are required.
# Window Resize Issue Workaround 
I had an issue with window resizing playing well with my textures. When resizing the window, my texture's position would not be correct. Only when I moved the window after resizing would the textures go to their expected positions. I attribute it to either a bug with Raylib where window data is not updated correctly, or my lack of understanding of the library. Either way, I was able to solve this issue by simply moving the window forward then back again with Raylib's API call, and this fixed it. Not preferable, but until I can find an amswer for this, it fixes the problem.
