# ScreenScaling
A template for screen scaling using Raylib and C++. We can use a virtual resolution to draw everything to and design our game around, and size up that texture up or down depending on the size of the window. Supports 1080p and 4k due to the intial dimensions of the virtual resolution being able to nicely multiply into those resolutions. Note that for aspect ratios that mismatch the original virtual resolution, white boxes will appear either vertically or horizontally to adjust to fit. If it's the same aspect ratio (like scaling up to fullscreen) the resolution will scale up evenly so no letterboxes are required.
